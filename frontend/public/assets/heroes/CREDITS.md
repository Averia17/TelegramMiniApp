# Katty visual reference

The Katty runtime model is converted from the user-provided local archive, based on [Tricky Janet by pyeerz on Sketchfab](https://sketchfab.com/3d-models/tricky-janet-86283dbe8ca54428a26b6b9033d624a1).

The shipped `katty_base.glb` is a static FBX import with its texture packed into the GLB. The source FBX and texture are retained under `frontend/assets-source/heroes/katty/source/`. The model has no authored animation clips, so the game uses its normal static-model runtime fallback for locomotion and ability presentation.
