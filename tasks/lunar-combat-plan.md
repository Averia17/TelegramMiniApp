# План: мгновенный бой и лунные ящики

## Цель

После перехода матча в `game` урон, атаки и способности доступны сразу. Ящики с лунными усилениями создаются в лобби, разрушаются только после старта и оставляют усиление.

## Срезы

1. Убрать боевую блокировку `landing`, начать матч с `hunt` и пересчитать таймеры фаз.
2. Добавить серверные лунные ящики: здоровье, случайное размещение, разрушение снарядами/ближними атаками и выдача награды.
3. Добавить усиления: скорость +15%/20 сек, урон +20%/15 сек, щит 300 HP на первый входящий удар, уменьшение primary cooldown на 5 сек.
4. Отрисовать ящики/цвета усилений и убрать landing-подсказку из HUD.

## Проверки

- Go: атака сразу после старта, генерация/разрушение/подбор ящика, сроки усилений.
- Frontend: рендер типов лут-пропов и фазовый HUD.
- `go test ./model/game ./model/prop`, `npm test`, `npm run build`.
