# План переработки Katty «Красколёт»

## Цель

Заменить мгновенный рывок Katty на короткое состояние полёта: герой получает повышенную скорость, проходит поверх blocking-коллизий, остаётся внутри океанской границы карты и после окончания способности автоматически приземляется в ближайшую свободную точку.

## Архитектурные решения

- Коллизии не отключаются глобально. Обычное движение и все остальные герои продолжают использовать текущий `MoveCircleWithBlockingWallsAndCircles`.
- Полёт — общий временный traversal-статус игрока (`FlyingUntil` + коэффициент скорости), чтобы будущие герои могли переиспользовать тот же путь без специальных исключений в базовом движении.
- Во время полёта проверяется только граница карты; стены, разрушаемые объекты и динамические наземные препятствия остаются под героем.
- При завершении полёта сервер сначала пытается оставить героя на текущем месте, затем ищет ближайшую свободную позицию с учётом радиуса героя, стен, динамических ящиков и границ карты. Позиция всегда авторитетно исправляется до следующего snapshot.
- Frontend prediction получает тот же статус `flying` и повторяет только wall-passable movement; authoritative snapshot остаётся источником истины при расхождении.

## Приёмка

- Katty во время Красколёта движется быстрее обычной скорости.
- Katty может пересечь blocking wall только в активном полёте.
- Никакой герой не может выйти за пределы карты/океанской границы через эту механику.
- После окончания полёта Katty не остаётся внутри стены, ящика или за границей; если текущая точка занята, выбирается ближайшая свободная.
- Обычное движение и существующие dash/knockback остальных героев не меняют правила коллизий.
